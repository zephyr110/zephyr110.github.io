项目概览

Zlog 是由 Zephyr110 从零开发的个人博客系统。前台与后台同一仓库，文章统一存放在 Turso（libSQL）。同一份代码对应两个独立部署目标——都读同一个库，但取数时机与能力不同：

部署目标 ①：Vercel（SSR + 后台）

数据流

浏览器访问页面或调用 API 时，Vercel Serverless 通过 @libsql/client 即时查询 Turso。内容改动写入库后，前台在 CDN 缓存过期后即可看到（vercel.json：s-maxage=60）。

mermaid

配置步骤

  1. 导入仓库：New Project → 选择 zlog，Framework Preset 为 Next.js
  2. Monorepo：Root Directory = apps/web；Build Command = pnpm build；Node.js 24
    • 不要用 pnpm export 部署到 Vercel（会失去 SSR 与后台）
  3. 环境变量：Settings → Environment Variables，按下方清单配置（Production / Preview 一致）
  4. 域名：默认 https://zephyr110.vercel.app，可绑自定义域名
  5. 何时重建：push main 只为代码/依赖变更；发文章不必 Redeploy

部署目标 ②：GitHub Pages（静态导出）

数据流

GitHub Actions 在 CI 里执行 pnpm export，构建阶段连上 Turso，把当时的文章渲染成静态文件，再发布到 Pages 仓库。线上静态站不再连库。

mermaid

配置步骤

仓库已有 .github/workflows/deploy.yml：

  1. 在主仓库 Secrets 配置：TURSO_DATABASE_URL、TURSO_AUTH_TOKEN、GH_PAT
  2. push main（或手动 workflow_dispatch）→ 执行 pnpm export
  3. 将 apps/web/out 发布到外部 Pages 仓库（如 zephyr110/zephyr110.github.io）
  4. Actions 里 NEXT_PUBLIC_SITE_URL 指向 Pages 域名（当前为 https://zephyr110.github.io）

静态站没有 /admin 与 /api。写作请用本地 pnpm dev 或 Vercel /admin；写完后需等（或触发）一次 Actions，镜像站才会更新。

刷新静态镜像

mermaid

也可只触发 workflow_dispatch（不必改代码），只要 Secrets 有效即可重新从 Turso 导出。

共用前置：GitHub 与 Turnstile

两个部署目标都会用到下列资源（Vercel 还需要完整服务端环境变量）：

  1. 主仓库 zephyr110/zlog：main 为发布分支。push 可同时触发 Vercel 重建代码 与 Actions 静态导出
  2. 图片仓库 zephyr110/blog-img（可用 BLOG_IMG_REPO 换名）：fine-grained token，仅该仓库 Contents: Read and write → BLOG_IMG_GITHUB_TOKEN
  3. Cloudflare Turnstile：免费 Cloudflare → Turnstile → Add site；NEXT_PUBLIC_TURNSTILE_SITE_KEY + TURNSTILE_SECRET_KEY。Domains 须包含生产域名（如 zephyr110.vercel.app）；本地可用官方测试 key（见 apps/web/.env.local.example）

对照小结

VercelGitHub Pages
构建pnpm buildpnpm export
取数请求时构建时
后台有无
发文写库即生效（~60s）需再跑 Actions
改代码push → 重建应用push → 重建静态站
  • 发布即入库：draft=1 不上线；发布后 Vercel 很快可见，Pages 等下次导出
  • 不必为发文 Redeploy Vercel；只有改代码才需要
  • 回滚：改回草稿；Vercel 很快消失，Pages 需再构建

注意事项

  • Turbopack root 误判：机器上多余的 package-lock.json 会让 workspace root 推断错误。在 next.config.ts 显式设置 turbopack.root
  • Turnstile 110200：Domains 白名单未含当前域名；换域名后记得同步
  • 改 Vercel Project Name：检查 NEXT_PUBLIC_* 并重新部署
  • Vercel ≠ 静态站：生产用 pnpm build；pnpm export 只给 GitHub Pages / 自托管 out/
